### 🚀 Featured Embedded Engineering Projects

#### 1. 🤖 Cybernetic Surveillance Rover
**Stack:** `Raspberry Pi 5` · `ESP32` · `C++` · `Python` · `Linux` · `Gemini Vision` · `Groq` · `Custom PCB & BMS` · `HTTP` · `Bluetooth RSSI`
- **Dual-AI Vision & Voice Pipeline:** Integrated Raspberry Pi camera feeds with a vision-language model pipeline (Gemini Vision & Groq) for real-time object recognition, OCR, and person detection alongside bidirectional Speech-to-Text and Text-to-Speech voice control.
- **Autonomous Navigation & RSSI Tracking:** Engineered 6-sensor IR obstacle avoidance using Linux GPIO interfaces and software PWM motor control, plus Bluetooth RSSI proximity detection to dynamically modulate speed and maintain user follow-distance.
- **Distributed IoT Control & Telemetry:** Connected Raspberry Pi and ESP32 nodes over local HTTP for smart home automation, paired with automated Python serial logging scripts for latency benchmarking and statistical sensor analysis.
- **Custom Hardware & BMS Design:** Designed a custom PCB for direct Raspberry Pi 5 peripheral interfacing and a multi-rail Battery Management System (BMS), completing full schematic capture, footprint creation, DRC/DFM verification, Gerber generation, and BOM preparation.

#### 2. 🚢 Marine Radar CAN-Based Smart Ship Monitoring & Collision-Avoidance System
**Stack:** `ARM LPC21xx` · `Embedded C` · `CAN 2.0B (125 kbps)` · `UART` · `PWM` · `HC-SR04` · `20x4 LCD` · `I2C/SPI EEPROM`
- **3-Node CAN 2.0B Architecture:** Architected a deterministic three-node ECU network on ARM LPC21xx microcontrollers communicating at `125 kbps` with independent signal broadcasting.
- **Bare-Metal Register Drivers:** Wrote a custom bare-metal CAN driver using direct register manipulation covering bit-timing configuration, message transmission/reception, and hardware acceptance filtering.
- **Ultrasonic Sweep & Display Engine:** Built a 3-state PWM servo radar sweep controller with microsecond/millisecond hardware timer delays for `HC-SR04` obstacle range validation, rendered live via a custom 4-bit parallel `20x4 LCD` driver and UART polling interface.
- **Non-Volatile Memory Characterization:** Interfaced external EEPROM/Flash memory over `I2C/SPI` to store persistent radar parameters and benchmarked read/write cycle endurance.
